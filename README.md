 
# 🌤️ Weather App
## 📌 Project Name
Weather App

## 📖 Description
This is a simple Weather App created using **HTML, CSS, and JavaScript**. It allows users to search for any city and view the current weather information using the WeatherAPI.

## 🚀 Features

- Search weather by city name
- Shows current temperature
- Displays city name and current date
- Weather condition with icon
- Cloud percentage
- Humidity
- Wind speed
- Air pressure
- Dynamic background image based on weather
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI

## 📁 Project Structure

```
Weather-App/
│
├── index.html

```

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a city name.
5. Click the Search button.
6. Weather details will be displayed.



## 📷 Output

- Weather Temperature
- City Name
- Current Date
- Weather Condition
- Weather Icon
- Cloud Percentage
- Humidity
- Wind Speed
- Pressure
